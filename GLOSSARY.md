# Deepfake Face Swap Engine

Real-time live deepfake face swapping engine in Rust, compositing target facial identities onto camera video streams and serving them via a virtual webcam.

## Language

**Target Face**:
The static identity face loaded from a reference photo whose facial features and likeness are transferred onto the video feed.
_Avoid_: Source image, avatar, replacement face, sample image

**Input Face**:
The live human face detected in the webcam video stream that provides the driving pose, expression, lighting, and head orientation.
_Avoid_: Host face, driving face, background face, user face

**Face Embedding**:
A 512-dimensional L2-normalized vector generated by the face recognition model representing a Target Face's unique identity.
_Avoid_: Latent vector, identity code, face fingerprint, latent feature

**Alignment Template**:
The standard 5-point facial landmark coordinate space ($128 \times 128$) used to normalize and crop faces prior to neural network inference.
_Avoid_: Landmark reference, canonical face, anchor layout

**Primary Face**:
The detected face within the camera stream having the largest bounding box area, selected for swapping to maintain deterministic real-time latency.
_Avoid_: Main face, focused face, front face

**Virtual Camera Sink**:
The software output stream registered with the operating system as a standard webcam device (via OBS Virtual Camera or Media Foundation) to feed external applications.
_Avoid_: Virtual webcam, video loopback, camera transmitter, fake camera

**Clean Passthrough**:
Streaming the unmodified webcam video feed directly to the Virtual Camera Sink when no face is detected or before a Target Face is loaded.
_Avoid_: Raw stream, bypass mode, fallback video, idle stream

**Temporal Filter**:
A low-latency smoothing filter (One-Euro filter) applied to landmark coordinates across consecutive frames to suppress jitter without adding lag.
_Avoid_: Smoothing algorithm, jitter reducer, landmark damper
